# Brasa Smash

Site de demonstração para portfólio de uma hamburgueria smash fictícia no Pontal, Ilhéus-BA.
Marca, endereço, telefone, cardápio e preços são fictícios.

Uma página só (`index.html`), com HTML, CSS e JavaScript juntos, sem dependências além das fontes do Google Fonts.

## O que tem

- Menu fixo com versão de celular
- Abertura com o hambúrguer em camadas levitando e adesivos que seguem o mouse
- Letreiro rolando
- Manifesto com palavras acendendo no scroll e pilha de polaroids
- Cupom fiscal impresso conforme o scroll
- Mais vendidos e cardápio com filtro por categoria
- Nossa História com colagem de fotos
- Janela "Pedir agora" (gaveta no celular) com WhatsApp, ligação e mapa
- Respeita a preferência de movimento reduzido do sistema

## Como abrir

Abra o `index.html` no navegador, ou sirva a pasta com qualquer servidor estático.
